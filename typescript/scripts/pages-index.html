Thumbrella JS

Serves the @thumbrella/client browser bundle for direct use in web pages - no build step.

Use a versioned path in a module script, for example https://js.thumbrella.dev/1/tbr.js for the latest 1.x, or pin an exact release like https://js.thumbrella.dev/1.4.0/tbr.js.
